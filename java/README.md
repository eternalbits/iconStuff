## The JPEG 2000 (JP2) icon

The JPEG 2000 (JP2) format is being used less and less, and we hope you won't need it.

### Convert JP2 to PNG Online

You can convert JP2 files to PNG format online using one of the several
 options that appear when searching for "JP2 to PNG" on the web.
 
- "Save As" a .jp2 (JPEG 2000) file.
- Open one of the conversion links.
- Upload the .jp2 file saved in the previous option.
- Choose PNG as the desired output format.
- Click convert and download your new image file.
- Open the image as PNG and copy it using the menu.
- Go to the original image and paste the copied image.
- Finally, delete the JP2 image.

### Convert JP2 to PNG Offline

You can convert JP2 files to PNG offline using desktop software like
 [NConvert](https://www.xnview.com/en/nconvert/), which processes files
 locally on your PC without an internet connection.
 
 - Find the most suitable connection for your device.
 - Download the zip file and install it in Program Files,
 /opt, /usr/local, ~/Documents, ~/Applications, ...
 - Go to `Settings` > `Programs that convert JPEG 2000 to PNG`
 and look for the nconvert program there.

### Convert ICO and ICNS disk icons when requested using parameters
```
Usage: java -jar Icons.jar -c <src> | -d <src>  [-f <fmt>] [-h] [-i <ico>]
       [-j <app>] [-o] [-v] [-w <out>]

To convert ICO to ICNS disk icons. Version 1.8

 -c, --copy <src>     copy <src> to a new image
 -d, --dump <src>     print <src> disk image details
 -f, --format <fmt>   copy output format: ICNS, ICO, PNG or JP2
 -h, --help           print this help and exit
 -i, --icon <ico>     a list with the icon and output
 -j, --jpeg <app>     program to convert JPEG 2000 to PNG
 -o, --overwrite      overwrite existing file on copy
 -v, --version        print version information and exit
 -w, --write <out>    set <out> as destination file for copy

One of --copy or --dump is required
--icon can be a phrase like
2=bit;3=*;4=64:bit;?=48:bit;?=24:bit for ICO or
1=ic05:png;2=ic04:bit;3=*;?=128:png for ICNS
```
